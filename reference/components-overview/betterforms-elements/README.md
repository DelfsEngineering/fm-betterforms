# Klai Studio Elements

This section covers the field types and input-oriented elements you can place on Klai Studio pages.

In practice, this section mixes three kinds of docs:

- Klai Studio-owned fields and wrappers
- Vue Form Generator-backed fields that Klai Studio still uses at runtime
- Compatibility-oriented pages where Klai Studio normalizes older field shapes into the current V3+ `fieldOptions` shape

When a field page shows `fieldOptions`, treat that as the canonical V3+ contract unless the page clearly says otherwise.

These pages focus on the Klai Studio-facing schema and behavior you need in the editor. Where a field ultimately comes from a dependency, the page should still describe the runtime shape Klai Studio expects.

Browse the sub-pages for the specific field you need.
